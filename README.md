# One Line, One Chill

A make.fun bounty entry: a program that writes a single original sentence of
horror — one line, under 200 characters, that frightens in one breath — to
`/output/entry.txt`.

The line:

> The voicemail from my own number ended with me saying goodnight, in a voice I have not used since I was seven.

Run it with Node 22 (stdlib only, deterministic — no clock, no randomness,
no network):

```sh
node main.ts
```
